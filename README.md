# SAE.S3.01 — Application type "Trello"

## Nom du projet

**SAE.S3.01_meziani_coquin_valeur--maselli_khalfouni**

> Application collaborative de type tableau Kanban (similaire à Trello) pour gérer des tâches, des listes et des tableaux.

---

## Description

Cette application permet de créer des **tableaux**, des **listes** à l'intérieur des tableaux et des **cartes** (tasks) à l'intérieur des listes. Chaque carte peut contenir un titre, une description, des étiquettes, une date d'échéance et des commentaires. L'objectif est d'offrir une interface simple et réactive pour organiser le travail en équipe.


## Utilisation rapide

* Créer un nouveau tableau (Board)
* Ajouter des listes (To Do, Doing, Done)
* Ajouter des cartes dans les listes
* Déplacer les cartes pour suivre l'avancement
